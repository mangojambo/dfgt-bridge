Nomes de produtos identificam os equipamentos; não indicam afiliação ou aprovação da Logitech.

`data-control` identifica hotspots e é compartilhado com os destinos/entradas do mapper. As duas posições com 300/301 no DFGT têm o mesmo identificador intencionalmente: o software não distingue controles físicos que compartilham um código. A/B do dial exigem confirmação por leitura real, sem comandos de motor.
